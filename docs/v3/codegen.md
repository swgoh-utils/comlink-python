# Code generation for the client matrix

`swgoh_comlink` ships **four** client classes — sync and async, each in
dict-default and typed-Struct flavours:

| Import | Default return | Use for |
|---|---|---|
| `from swgoh_comlink import SwgohComlink` | `dict[str, Any]` | v2 wire compat |
| `from swgoh_comlink import SwgohComlinkAsync` | `dict[str, Any]` | v2 wire compat (async) |
| `from swgoh_comlink.typed import SwgohComlink` | `msgspec.Struct` | Typed attribute access |
| `from swgoh_comlink.typed import SwgohComlinkAsync` | `msgspec.Struct` | Typed attribute access (async) |

All four classes are **generated** from a single manifest. This page is
the contributor guide for working with the generator.

## Folder layout

```
src/swgoh_comlink/
├── _codegen/
│   ├── endpoints.py            ← single source of truth (manifest)
│   ├── templates/
│   │   └── client.py.jinja     ← one template, parameterised on is_async + is_typed
│   ├── generate.py             ← writes the 4 files below + runs ruff
│   └── README.md
├── _escape_hatches_sync.py     ← hand-written mixin: healthcheck, raw_request, stream_*
├── _escape_hatches_async.py    ← async twin
├── swgoh_comlink.py            ← GENERATED dict-default sync
├── swgoh_comlink_async.py      ← GENERATED dict-default async
└── typed/
    ├── __init__.py             ← hand-written: re-exports
    ├── swgoh_comlink.py        ← GENERATED typed sync
    └── swgoh_comlink_async.py  ← GENERATED typed async
```

Generated files start with `# AUTOGENERATED — DO NOT EDIT.` and a
pre-commit hook (`codegen-drift`) refuses commits where they diverge
from the manifest.

## Regenerating

```bash
make generate
# equivalent:
uv run python -m swgoh_comlink._codegen.generate
```

The generator writes the four output files, then runs
`ruff check --fix` (which includes import sorting) and `ruff format`.
Generator whitespace doesn't matter — ruff is the source of truth for
the final file shape.

## Adding an endpoint

1. **Open `src/swgoh_comlink/_codegen/endpoints.py`** and append one
   `Endpoint(...)` entry to `ENDPOINTS`.

2. **For a uniform endpoint** (payload from a builder, no special
   logic), the entry looks like:

   ```python
   Endpoint(
       name="get_my_thing",
       http_method="POST",
       path="myThing",
       docstring="One-line method docstring.",
       params=(
           Param("foo", "str"),
           Param("bar", "int", default="0"),
       ),
       payload_builder="my_thing_payload",
       aliases=("getMyThing",),
   )
   ```

3. **For a typed endpoint** (returns a Struct, accepts `raw=`), add:

   ```python
       typed_decoder="MY_THING_DECODER",
       typed_return="MyThing",
   ```

   Or for envelope-unwrap semantics like `/guild`:

   ```python
       typed_decoder_callable="decode_my_thing",
       typed_return="MyThing",
       dict_decoder_callable="decode_my_thing_dict",
   ```

4. **For quirks** (pre-fetch metadata fallback, stats sub-service,
   custom timeout, `@param_alias` decorator, inline payload), the
   relevant flags are documented in the `Endpoint` dataclass fields.

5. **Regenerate and verify:**

   ```bash
   make generate
   make generate-check   # confirms idempotent
   uv run pytest tests/v3/test_codegen_invariants.py -q
   ```

6. **Commit the manifest change + the four regenerated files in the
   same commit.** The pre-commit hook will block a manifest change
   without its corresponding regenerated output.

## When to bypass the manifest

Methods with non-uniform shape stay hand-written in mixins:

- `healthcheck` — `bool` return, exception-safe, bypasses retry.
- `raw_request` — `httpx.Response` return.
- `stream_game_data` / `stream_localization` — streaming context
  managers, bypass retry.
- `get_latest_game_data_version` — wraps `get_game_metadata`.

These live in `_escape_hatches_sync.py` / `_escape_hatches_async.py`.
The generated client classes inherit from the appropriate mixin.

If a new endpoint genuinely doesn't fit the manifest shape, add it to
the mixin — don't bend the manifest schema to accommodate one outlier.

## Reading the generated files

Generated files have:

- A `# AUTOGENERATED — DO NOT EDIT.` banner pointing to the source.
- Imports + module docstring tailored to the (sync/async, dict/typed) variant.
- `class SwgohComlink(SwgohComlinkBase, _SyncEscapeHatchMixin):` (or its 3 cousins).
- `__init__`, lifecycle (`__enter__`/`__exit__` or `__aenter__`/`__aexit__`),
  `_request` / `_post` / `_get_game_version`.
- One method per `Endpoint` in the manifest, followed by alias
  assignments (`getMyThing = get_my_thing`).

If something in the generated output looks wrong, edit the manifest
(for endpoint shape) or the template (for boilerplate). Never edit a
generated file directly — your edit will be overwritten on the next
`make generate`.

## The codegen invariant tests

`tests/v3/test_codegen_invariants.py` exercises the generator's output
without exercising the wire:

- Every manifest endpoint exists on all four client classes.
- Every alias resolves to the canonical method.
- Sync and async signatures match within a surface (modulo `async`).
- Dict and typed signatures have the same parameter names; only `raw`'s
  default differs (`False` on typed, `True` on dict for source-compat).

Plus two end-to-end parity tests: dict client returns dict for
`get_player`; typed client returns `Player` Struct.

A failure in these tests means the generator drifted from its contract
— check the template + manifest before touching anything else.
