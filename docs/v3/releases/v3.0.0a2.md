The second community-tryable v3 alpha. `3.0.0a2` is `3.0.0a1` plus everything
that shipped on the upstream v2 line as v2.3.0, v2.3.1, v2.4.0 and v2.5.0, ported
onto the v3 generated clients, plus a change to the retry API (see
[Breaking changes since a1](#breaking-changes-since-a1)). Bug reports welcome via
the `v3` issue label.

## Install

This alpha is hosted on the maintainer fork
[MarTrepodi/comlink-python](https://github.com/MarTrepodi/comlink-python);
the upstream `swgoh-utils` repo stays on v2.x until reintegration.

```bash
pip install https://github.com/MarTrepodi/comlink-python/releases/download/v3.0.0a2/swgoh_comlink-3.0.0a2-py3-none-any.whl
```

Or from a git ref:

```bash
pip install git+https://github.com/MarTrepodi/comlink-python.git@v3.0.0a2
```

**Recommended:** install into a dedicated virtual environment with a
rollback path to the public v2.x release — see
[`docs/v3/install-alpha.md`](../install-alpha.md).

The PyPI package `swgoh_comlink` is **still v2.x** — `pip install
--pre swgoh_comlink` will NOT pick up this alpha.

## Breaking changes since a1

- **Retry API replaced.** The `max_retries=` keyword (retrying 408/425/429/5xx three
  times by default) and its private `_retry.py` module are removed. Retrying is now
  **opt-in** through the keyword-only `retry: RetryPolicy | None = None` argument,
  the same policy the v2.4.0 line ships:

  ```python
  from swgoh_comlink import RetryPolicy, SwgohComlink

  client = SwgohComlink(retry=RetryPolicy(attempts=3, min_interval=0.4))
  ```

  The default (`retry=None`) makes exactly one attempt and never waits. A policy
  retries rate refusals (HTTP 429 or the game's `Rate exceeded!`) and HTTP 503,
  honours `Retry-After`, adds jitter, and can pace calls per endpoint.
  `with_options(retry=...)` replaces `with_options(max_retries=...)`. The
  `profile=` connection-pool presets (`default` / `bot` / `bulk`) and
  `http_client=` injection are unchanged.
- **Typed HTTP errors.** An HTTP error status now raises `SwgohComlinkHTTPError` or one
  of its subclasses (`SwgohComlinkRateLimitError`, `SwgohComlinkUnavailableError`,
  `SwgohComlinkClientError`) instead of a plain `SwgohComlinkException("HTTP nnn")`.
  `str(exc)` is unchanged, and all of them still subclass `SwgohComlinkException`.
  Each carries `status`, `code`, `detail`, `retry_after` and `response`.
- **`get_game_data(items=...)`** accepts any in-range bitmask, including single
  collections (`DataItems.UNITS`); combine members with `|`, not `+`.

## Highlights

Everything below arrived from the upstream v2.3.0 – v2.5.0 releases unless noted.

### Client

- **Version cache.** `/metadata` game and localization versions are cached per
  client (`version_cache_ttl`, default 3600 s; `invalidate_version_cache()`;
  `get_latest_game_data_version(refresh=True)`).
- **`get_enums()` cache.** The response is cached per game data version; pass
  `refresh=True` to re-fetch.
- **`RetryPolicy`** with `attempts`, `backoff`, `jitter`, `max_retry_after`,
  `min_interval` and `unpaced_endpoints`; endpoint holds after a rate refusal are
  shared by concurrent async callers, and a cancelled wait gives its pacing slot back.
- **Exceptions** no longer log tracebacks from their constructors; typed HTTP errors
  are picklable and copyable.
- **`py.typed`** marker: the package ships inline type hints (PEP 561).

### Bug fixes carried from v2.3.x – v2.5.0

- **HMAC:** the signature covers the bytes actually sent, so empty-payload signed
  POSTs such as `get_game_metadata()` validate instead of returning 403.
- **`/metadata`:** the request sends the `clientSpecs` key that comlink expects
  (was `client_specs`).
- **StatCalc:**
  - a mod without a set keeps its stats;
  - `purchasedAbilityId` is carried through raw unit normalization, so ultimate
    ability Galactic Power is no longer lost. This includes the typed fast path,
    which previously dropped it;
  - gear slots resolve for slot-less equipment entries;
  - ships with an incomplete crew are skipped instead of aborting a roster;
  - the game data builder reads bools and non-finite numbers as 0.
- **Helpers:** relic offset of 2 in `convert_relic_tier`; UTC, timezone-aware
  `get_arena_payout`; `get_playable_units` tolerates missing fields and enum
  rarity; `get_guild_members` requests guild activity info; unit name keys with
  variant suffixes such as `_NAME_V2`; conquest feats whose id has no kind token;
  terminal and Discord styles are closed correctly; payload ints reject
  non-finite numbers.
- **`swgoh-migrate`:** scan excludes are additive, glob-aware and root-relative.

### New helpers

Territory Battle definitions, unit upgrade costs, unit abilities and named effects,
item, reward and id-catalog naming (`ItemNames`, `ItemType` / `CurrencyType`
tables), `get_game_config` / `get_game_config_int`, `get_event_schedule`,
`get_guild_activity`, `get_conquest_feats`, `calc_stamina_full_time`, wire-value
readers for loosely typed payload values, and sync-named helpers that accept async
clients. See the [helpers API reference](../../api/helpers.md).

### Packaging, CI and docs

- Python ≥ 3.11 (unchanged from a1); CI runs 3.11 – 3.14 with the optional extras
  installed and a 95 % coverage gate, plus the codegen drift gate.
- ruff and `ty` run from `uv.lock`; commitlint is pinned and shares one
  `.commitlintrc.json` between pre-commit and CI; examples are linted and formatted.
- Community files: `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`,
  `CITATION.cff`, refreshed issue and PR templates.
- New docs pages for the typed errors and retry policy, expanded helper reference,
  and a docs site workflow.

## Fixes to the a1 notes

The `3.0.0a1` notes described the retry policy as stamina-based and said `click`
moved behind a `[migrate]` extra. Neither was accurate: the a1 retry policy was
hand-rolled, and no `[migrate]` extra existed. (The a1 retry policy is gone in
this release in any case.)

## Known limitations

The a1 limitations still apply: pure-Python only (ADR-0007), no StatCalc
parallelism (ADR-0006), `StatCalcAsync` only makes game-data fetching async, and
bimorphic Struct overhead of about 10 %.
