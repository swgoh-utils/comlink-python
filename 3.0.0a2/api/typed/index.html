    Typed clients¶

    swgoh_comlink.typed has the same two clients as the top-level package, with the same constructor arguments, methods and retry behaviour. The difference is the return type of four endpoints:

    Method swgoh_comlink.SwgohComlink swgoh_comlink.typed.SwgohComlink
    get_player dict Player
    get_guild dict Guild
    get_game_metadata dict Metadata
    get_leaderboard dict LeaderboardResponse

    The typed results are msgspec.Struct objects. Their fields are the wire's camelCase names in snake_case (player.guild_id for guildId). Every other endpoint returns a dict on both surfaces.

    from swgoh_comlink.typed import SwgohComlink

with SwgohComlink() as comlink:
    player = comlink.get_player(allycode=245866537)
    print(player.name, len(player.roster_unit))

    The raw=True escape hatch¶

    Pass raw=True to any of the four methods to get the v2 dict for that call instead of a Struct. The dict-default clients accept the same keyword and ignore it, so code that passes it works with either import.

    player = comlink.get_player(allycode=245866537, raw=True)
print(player["name"])

    StatCalc takes the typed results as they are: calc_player_stats() accepts a Player, and calc_roster_stats() accepts its roster_unit list. See the typed StatCalc recipe and the v2 → v3 migration guide for more.

    API Reference¶

    SwgohComlink ¶

    Bases: SwgohComlinkBase, _SyncEscapeHatchMixin

    Typed-Struct synchronous interface for the swgoh-comlink service.

    Endpoint methods that have a typed return value (get_player, get_guild, get_game_metadata, get_leaderboard) return a :class:msgspec.Struct by default. Pass raw=True per call for the v2-compatible dict[str, Any] shape.

    Parameters:

    Name Type Description Default
    url str

    The URL where swgoh-comlink is running. Defaults to http://localhost:3000.

    		 required
    access_key str

    The HMAC public key. Default None (HMAC not used).

    		 required
    secret_key str

    The HMAC private key. Default None (HMAC not used).

    		 required
    host str

    IP/DNS of the host where swgoh-comlink is running.

    		 required
    port int

    The port number where the comlink service is listening.

    		 required
    stats_url str

    URL of the swgoh-stats sub-service if different from url.

    		 required
    stats_port int

    The port number where the swgoh-stats sub-service is listening.

    		 required
    verify_ssl bool

    Whether to verify TLS certificates. [Default: True]

    		 required
    version_cache_ttl float

    Seconds to cache the game/localization versions fetched from /metadata. 0 disables caching; math.inf caches for the client lifetime. [Default: 3600]

    		 required
    retry RetryPolicy | None

    Retry rate refusals and HTTP 503 responses, and optionally space calls to the same endpoint, as described by a :class:~swgoh_comlink.retry.RetryPolicy. [Default: None, one attempt per call and no waiting]

    		 required
    http_client Client | None

    A pre-built httpx.Client. SDK won't close it; caller owns its lifecycle.

    		 None
    profile str

    Connection pool preset ("default" / "bot" / "bulk").

    		 'default'

    All arguments are keyword-only.

    Raises:

    Type Description
    SwgohComlinkHTTPError

    From every endpoint method when the service answers with an HTTP error status (after any retries the retry policy allows). Subclasses identify rate refusals, HTTP 503 and other 4xx statuses.
    SwgohComlinkException

    On transport and decoding errors.
