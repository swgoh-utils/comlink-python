    SwgohComlinkAsync API¶

    SwgohComlinkAsync provides the same API as SwgohComlink with async/await support. All public methods have identical signatures — just add await to each call.

    Quick Start¶

    from swgoh_comlink import SwgohComlinkAsync

async with SwgohComlinkAsync() as comlink:
    player = await comlink.get_player(allycode=245866537)
    guild = await comlink.get_guild(guild_id=player["guildId"])

    Without a context manager, call aclose() when done:

    comlink = SwgohComlinkAsync()
try:
    player = await comlink.get_player(allycode=245866537)
finally:
    await comlink.aclose()

    Connecting to Comlink¶

    SwgohComlinkAsync takes the same constructor arguments as the synchronous client: url or host/port to choose the service, and access_key/ secret_key (or the ACCESS_KEY/SECRET_KEY environment variables) for HMAC signing. See Connecting to Comlink.

    async with SwgohComlinkAsync(host="192.168.1.10", port=3000) as comlink:
    ...

    Handling Errors¶

    Failed calls raise the same typed HTTP errors as the synchronous client.

    Retries and Pacing¶

    The retry argument takes the same RetryPolicy as the synchronous client. Waits use asyncio.sleep, so they do not block the event loop. Pacing and the hold after a rate refusal apply across concurrent tasks on one client, and the tasks start in the order they asked. A task cancelled while it waits gives its slot back, so cancelling a batch does not delay the calls that follow it:

    import asyncio

from swgoh_comlink import RetryPolicy, SwgohComlinkAsync

async with SwgohComlinkAsync(retry=RetryPolicy(min_interval=0.4)) as comlink:
    players = await asyncio.gather(*(comlink.get_player(allycode=code) for code in allycodes))

    Stat Calculation¶

    For local stat calculation in async code, use StatCalcAsync which fetches game data without blocking the event loop:

    from swgoh_comlink import StatCalcAsync, SwgohComlinkAsync

async with SwgohComlinkAsync() as comlink:
    calc = await StatCalcAsync.create()
    player = await comlink.get_player(allycode=245866537)
    calc.calc_roster_stats(player["rosterUnit"])

    See the StatCalc API for full details.

    API Reference¶

    SwgohComlinkAsync ¶

    Bases: SwgohComlinkBase, _AsyncEscapeHatchMixin

    Dict-returning asynchronous interface for the swgoh-comlink service.

    Every endpoint method returns dict[str, Any] — byte-compatible with v2's wire shape. For typed :class:msgspec.Struct returns, use from swgoh_comlink.typed import SwgohComlinkAsync instead.

    Parameters:

    Name Type Description Default
    url str

    The URL where swgoh-comlink is running. Defaults to http://localhost:3000.

    		 required
    access_key str

    The HMAC public key. Default None (HMAC not used).

    		 required
    secret_key str

    The HMAC private key. Default None (HMAC not used).

    		 required
    host str

    IP/DNS of the host where swgoh-comlink is running.

    		 required
    port int

    The port number where the comlink service is listening.

    		 required
    stats_url str

    URL of the swgoh-stats sub-service if different from url.

    		 required
    stats_port int

    The port number where the swgoh-stats sub-service is listening.

    		 required
    verify_ssl bool

    Whether to verify TLS certificates. [Default: True]

    		 required
    version_cache_ttl float

    Seconds to cache the game/localization versions fetched from /metadata. 0 disables caching; math.inf caches for the client lifetime. [Default: 3600]

    		 required
    retry RetryPolicy | None

    Retry rate refusals and HTTP 503 responses, and optionally space calls to the same endpoint, as described by a :class:~swgoh_comlink.retry.RetryPolicy. [Default: None, one attempt per call and no waiting]

    		 required
    http_client AsyncClient | None

    A pre-built httpx.AsyncClient. SDK won't close it; caller owns its lifecycle.

    		 None
    profile str

    Connection pool preset ("default" / "bot" / "bulk").

    		 'default'

    All arguments are keyword-only.

    Raises:

    Type Description
    SwgohComlinkHTTPError

    From every endpoint method when the service answers with an HTTP error status (after any retries the retry policy allows). Subclasses identify rate refusals, HTTP 503 and other 4xx statuses.
    SwgohComlinkException

    On transport and decoding errors.

    get_enums(refresh=False) async ¶

    Get the game data enums. Uses GET (not POST).

    The response is cached on the instance as enums, with the game data version it was fetched under as enums_version. Later calls return the cached response while the game data version (read through the version cache, see version_cache_ttl) is unchanged. When the version cannot be determined, the enums are fetched and returned uncached. refresh=True fetches the version and the enums again. A cached response is the same object as enums: copy it before changing it.
