# `_codegen/` — client class generator

The four client variants are **generated** from a single manifest:

```
src/swgoh_comlink/
├── _codegen/
│   ├── endpoints.py            ← single source of truth
│   ├── templates/
│   │   └── client.py.jinja     ← one template, two axes
│   └── generate.py             ← writes the 4 files below
├── swgoh_comlink.py            ← GENERATED: sync, dict-returning
├── swgoh_comlink_async.py      ← GENERATED: async, dict-returning
└── typed/
    ├── swgoh_comlink.py        ← GENERATED: sync, typed-Struct
    └── swgoh_comlink_async.py  ← GENERATED: async, typed-Struct
```

The generated files start with `# AUTOGENERATED — DO NOT EDIT.` and a
pre-commit hook refuses commits where they diverge from the manifest.

## Regenerating

```bash
make generate
# or:
uv run python -m swgoh_comlink._codegen.generate
```

The generator writes the four output files then runs `ruff format` on
them, so generator whitespace doesn't matter.

## Adding an endpoint

1. Add one `Endpoint(...)` entry to `ENDPOINTS` in `endpoints.py`.
2. Run `make generate`.
3. Commit the manifest change AND the four regenerated files together.
4. Update tests + docs if the new endpoint introduces user-visible behavior.

The `Endpoint` dataclass covers the common cases:
- **Payload from a builder** → `payload_builder="my_payload_func"`.
- **Inline payload** → `inline_payload='{"foo": bar}'`.
- **Typed return** → `typed_decoder="MY_DECODER"`, `typed_return="MyStruct"`.
- **Decoder helper (envelope unwrap)** → `typed_decoder_callable="decode_my_thing"`.
- **Pre-fetch metadata fallback** → `pre_fetch_version=True` (for `get_game_data`-style).
- **Stats sub-service routing** → `stats_sub_service=True`.
- **Custom timeout** → `timeout_const="GAME_DATA_TIMEOUT"`.
- **camelCase shim names** → `aliases=("getMyThing",)`.
- **`@param_alias` decorator** → `param_aliases={"snake_name": "camelName"}`.

## When NOT to use the manifest

Methods with non-uniform shape stay hand-written in mixins. Today these
are: `healthcheck`, `raw_request`, `stream_game_data`,
`stream_localization`, `get_latest_game_data_version`. They live in:

```
src/swgoh_comlink/_escape_hatches_sync.py
src/swgoh_comlink/_escape_hatches_async.py
```

The generated client classes inherit from the appropriate mixin so the
public surface is whole.

## Why this exists

Two duplication axes: **sync/async × dict/typed**. Hand-maintaining 4
parallel client classes with 15+ near-identical endpoint methods each
doesn't scale. The manifest collapses the surface to one source.

See `docs/adr/0005-typed-dict-client-split.md` for the architectural
rationale.
