# Getting Help

## Questions and usage help

- **Documentation:** [swgoh-utils.github.io/comlink-python](https://swgoh-utils.github.io/comlink-python/) —
  API reference, the [migration guide](docs/migration.md), and [examples](examples/README.md)
- **Discord:** ask in the [swgoh-utils Discord server](https://discord.gg/6PBfG5MzR3). This is the fastest way to
  get help from the community and maintainers
- **Comlink service docs:** the [swgoh-comlink wiki](https://github.com/swgoh-utils/swgoh-comlink/wiki) covers
  running the service itself and what each endpoint returns

Please don't open GitHub issues for usage questions. Issues are for bugs and feature requests.

## Where to report what

| Problem | Where |
|---------|-------|
| Bug in this Python library | [Open a bug report](https://github.com/swgoh-utils/comlink-python/issues/new/choose) |
| Feature idea for this library | [Open a feature request](https://github.com/swgoh-utils/comlink-python/issues/new/choose) |
| Missing or wrong documentation | [Open a documentation issue](https://github.com/swgoh-utils/comlink-python/issues/new/choose) |
| Security vulnerability | **Privately** — see [SECURITY.md](SECURITY.md) |
| Comlink service problem (game data, Docker image, service errors) | [swgoh-comlink issues](https://github.com/swgoh-utils/swgoh-comlink/issues) |
